Pixel CSS

Pixel CSS is a framework-agnostic CSS library with a pixel-art aesthetic. Find a demonstration of its features below. The code is available on GitHub.

Dark Mode
Pixel CSS has a mode.
+ - 
<!--- HTML --->
<button class="btn btn-primary" id="theme-toggle">Light</button>

// JavaScript
const themeToggle = document.getElementById('theme-toggle')

if (themeToggle) {
  let isDark = window.matchMedia('(prefers-color-scheme: dark)').matches
  themeToggle.textContent = isDark ? 'Light' : 'Dark'

  themeToggle.addEventListener('click', () => {
    isDark = !isDark
    document.documentElement.dataset.theme = isDark ? 'dark' : 'light'
    themeToggle.textContent = isDark ? 'Light' : 'Dark'
  })
}

Copy Button
This panel has a copy button and a details area which provides documentation. 
Some text to copy
+ - 
<div class="panel-extra">
  <pre><code>Some text to copy</code></pre>
  <div class="copy-actions">
    <button class="btn btn-neutral" data-copy-btn>copy</button>
  </div>
</div>

document.querySelectorAll('[data-copy-btn]').forEach((btn) => {
  btn.addEventListener('click', () => {
    const code = btn.closest('.panel-extra')!.querySelector('code')!.textContent ?? ''
    navigator.clipboard.writeText(code)
    btn.textContent = 'copied!'
    setTimeout(() => {
      btn.textContent = 'copy'
    }, 1500)
  })
})
